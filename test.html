See items overflow/squish. --- ## Experiment 4 Change: ```css gap:20px; ``` TO: ```css gap:60px; ``` Observe spacing. --- ## Experiment 5 Change: ```css flex:1; flex:2; flex:3; ``` TO: ```css flex:1; flex:1; flex:1; ``` Now all boxes become equal. --- # FINAL REAL-WORLD UNDERSTANDING | Property | What It Controls | | --------------- | -------------------- | | display:flex | activates flexbox | | flex-direction | row or column | | justify-content | main axis alignment | | align-items | cross axis alignment | | flex-wrap | wrapping behavior | | gap | spacing | | flex | item sizing | --- # MOST IMPORTANT FLEXBOX SECRET When direction changes: ```css flex-direction:column; ``` Main axis ALSO changes. So: * justify-content becomes vertical * align-items becomes horizontal This is where most beginners get confused.
